# Security Policy

## Reporting a vulnerability

Email **security@quirence.ai**. Please do not open a public issue.

This covers Rinkata (rinkata.dev, api.rinkata.dev, the MCP endpoint, the rinkata CLI and its local MCP server, and this plugin) and every other Quirence product.

The full policy, including scope, safe harbor, and response times, is at https://rinkata.dev/security.
